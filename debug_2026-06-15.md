## Causa raíz: la URL que devuelve NocoDB es una ruta relativa sin el token

En `_render_attachments` extraes la URL así:

```python
url = att.get("url", "")
```

NocoDB v2 devuelve los adjuntos con **dos campos de URL**:
- `url` — ruta relativa de almacenamiento interno, tipo `download/noco/...` o `/api/v2/storage/...`. No es pública ni directamente descargable.
- `signedUrl` — URL firmada con token temporal, descargable directamente sin autenticación. Es la que se debe usar.

Tu `_resolve_attachment_url` intenta arreglar esto prefijando `base_url`, pero si NocoDB usa almacenamiento local, la URL resultante sigue requiriendo el header `xc-token` para autenticarse — y tu `_download_attachment_file_sync` SÍ lo agrega correctamente. Entonces la descarga debería funcionar... salvo por la segunda causa.

## Segunda causa: `_on_download_attachment` no usa `run_async`

Mira este bloque en `_on_download_attachment`:

```python
# Descarga síncrona
result = self._download_attachment_file_sync(url, save_path)
on_download_done(result)
```

Estás llamando `_download_attachment_file_sync` **directamente en el hilo de UI** (no en `run_async`). Si la descarga tarda más de unos pocos milisegundos, Qt congela el evento loop mientras espera — y en ese estado congelado **el `QFileDialog` ya cerró pero la UI no respondió, y si hay algún error en la red simplemente nada se muestra** porque el hilo de UI estaba bloqueado cuando el `show_notification` intentó ejecutarse.

Lo mismo pasa en `_on_open_attachment` — también llama directo sin `run_async`.

## La tercera causa: la URL firmada expira

Si el email fue recibido hace tiempo, la `signedUrl` de NocoDB ya expiró. Necesitas usar `url` + header de autenticación (lo que ya hace `_download_attachment_file_sync`), **no** `signedUrl`. Así que la estrategia de tu código es correcta en ese sentido.

## Fix concreto

Solo hay que tocar `_render_attachments` (para usar `signedUrl` con fallback a `url`) y mover las descargas a `run_async`. Aquí los cambios exactos:

**En `_render_attachments`, línea donde extraes la URL:**

```python
# ANTES:
url = att.get("url", "")

# DESPUÉS:
# signedUrl es la URL temporal firmada que NocoDB genera para descarga directa.
# Si no existe (almacenamiento local o URL ya expirada), usamos 'url' con auth header.
url = att.get("signedUrl") or att.get("url", "")
```

**En `_on_open_attachment`, reemplazar la llamada síncrona:**

```python
def _on_open_attachment(self, url: str) -> None:
    """Descarga el adjunto a un archivo temporal y lo abre."""
    try:
        ext = Path(url.split("?")[0].split("#")[0]).suffix or ".tmp"
        with tempfile.NamedTemporaryFile(delete=False, suffix=ext) as tmp:
            tmp_path = tmp.name

        if hasattr(self.main_window, "show_notification"):
            self.main_window.show_notification(
                "Descargando adjunto…", "info", duration_ms=2000
            )

        def on_done(result):
            if result.success:
                logging.getLogger("tardis").info("Abriendo adjunto: %s", tmp_path)
                try:
                    if sys.platform == "win32":
                        os.startfile(tmp_path)
                    elif sys.platform == "darwin":
                        subprocess.Popen(["open", tmp_path])
                    else:
                        subprocess.Popen(["xdg-open", tmp_path])
                except Exception as e:
                    if hasattr(self.main_window, "show_notification"):
                        self.main_window.show_notification(
                            f"No se pudo abrir el archivo: {e}", "error"
                        )
            else:
                err = result.errors[0] if result.errors else "Error al descargar"
                if hasattr(self.main_window, "show_notification"):
                    self.main_window.show_notification(err, "error")
                try:
                    os.unlink(tmp_path)
                except Exception:
                    pass

        run_async(
            self._download_attachment_file_sync,
            url,
            tmp_path,
            on_success=on_done,
            on_error=lambda e: self.main_window.show_notification(
                f"Error al descargar: {e}", "error"
            ) if hasattr(self.main_window, "show_notification") else None,
        )
    except Exception:
        logging.getLogger("tardis").exception("Error en _on_open_attachment")
```

**En `_on_download_attachment`, ídem:**

```python
def _on_download_attachment(self, url: str, default_name: str) -> None:
    """Descarga un adjunto a una ubicación elegida por el usuario."""
    save_path, _ = QFileDialog.getSaveFileName(
        self, "Guardar archivo", default_name, "Todos los archivos (*.*)"
    )
    if not save_path:
        return

    if hasattr(self.main_window, "show_notification"):
        self.main_window.show_notification(
            "Descargando…", "info", duration_ms=2000
        )

    def on_done(result):
        if hasattr(self.main_window, "show_notification"):
            if result.success:
                self.main_window.show_notification(
                    f"Archivo descargado: {Path(save_path).name}", "success"
                )
            else:
                err = result.errors[0] if result.errors else "Error al descargar"
                self.main_window.show_notification(err, "error")

    run_async(
        self._download_attachment_file_sync,
        url,
        save_path,
        on_success=on_done,
        on_error=lambda e: self.main_window.show_notification(
            f"Error al descargar: {e}", "error"
        ) if hasattr(self.main_window, "show_notification") else None,
    )
```
